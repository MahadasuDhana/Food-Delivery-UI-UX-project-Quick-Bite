# QuickBite – Food Delivery UI/UX Project

QuickBite is a responsive food-delivery web experience designed as a UI/UX portfolio project. The project focuses on simple food discovery, clear restaurant information, a low-friction cart flow, and responsive layouts.

## Project Goal

Design and implement a modern food-ordering experience that helps users:

1. Discover restaurants quickly.
2. Search for dishes or restaurants.
3. Filter restaurants by cuisine.
4. Add food to a cart.
5. Review the cart and complete a simulated checkout.

## UX Problem

Food-delivery users often have to scan large amounts of information before deciding what to order. QuickBite reduces this friction by presenting the most useful information—cuisine, rating, price level, and delivery time—in a compact restaurant card.

## Target Users

- College students
- Young professionals
- Users ordering food from local restaurants
- People who want quick and simple food discovery

## User Flow

Home
→ Search / Category
→ Restaurant discovery
→ Add item
→ Cart
→ Checkout confirmation

## Design Decisions

### Visual hierarchy
Large headline and clear primary actions guide users toward food discovery.

### Restaurant cards
Each card highlights restaurant name, rating, cuisine, delivery time and price level.

### Search
The search bar supports restaurant names, cuisines and sample menu items.

### Responsive design
The layout changes from multi-column desktop cards to a single-column mobile layout.

## How to Run

1. Download or clone the repository.
2. Open `index.html` in a browser.
3. Search for food, filter categories and test the cart.

For the best development experience, open the folder in VS Code and use the Live Server extension.
